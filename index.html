Arrastra sobre la plastilina para moldearla.
Con Mover, arrastra una pieza; con Shift se desliza por el suelo.
Con Escalar, arrastra hacia arriba para agrandar y hacia abajo para reducir.
Con Rotar, arrastra para girar la pieza; con Shift gira sobre sí misma.
Con Eliminar, haz clic en una pieza para quitarla (puedes deshacerlo).
Clic derecho + arrastrar para girar la vista.
Rueda del ratón para acercar o alejar.
